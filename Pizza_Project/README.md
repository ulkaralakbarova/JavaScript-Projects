 Pizza Project – Ulkar Pizza

 Pizza Project is an interactive pizza ordering application created with HTML, CSS, and JavaScript.

The application allows the user to customize a pizza and automatically calculates the order total.

 Pizza Size Options

- Personal Pizza
- Medium Pizza
- Large Pizza
- Extra Large Pizza

 Vegetable Toppings

- Mushrooms
- Onions
- Tomatoes
- Olives
- Green Peppers

 Meat Toppings

- Pepperoni
- Sausage
- Canadian Bacon
- Ground Beef
- Anchovy
- Chicken

 Pizza Project Features

- Select a pizza size
- Select multiple vegetable toppings
- Select multiple meat toppings
- Calculate the pizza price
- Apply topping pricing
- Display selected items
- Display the final order total
- Use JavaScript functions to process the order
- Use CSS to customize the appearance of the application
